# ResQHub: A LORA MODEL FOR EMERGENCY ASSISTANCE AND EVACUATION GUIDANCE

ResQHub is a capstone project that aims to improve emergency communication, incident reporting, and evacuation guidance in Baguio City particularly in Military Cut-off.

The system is designed to help residents communicate emergency situations and receive important information, while providing barangay personnel and emergency responders with a way to monitor and coordinate reported incidents.

## About the Project

During disasters and emergencies, communication can become difficult due to power interruptions, weak internet connections, and unavailable mobile networks. These challenges can delay emergency reporting and the distribution of important information.

ResQHub aims to address these challenges by developing an emergency assistance system that integrates a mobile application, backend services, a database, and LoRa-based communication.

## Objectives

- Provide residents with a platform for reporting emergencies.
- Improve the distribution of emergency alerts and notifications.
- Provide accessible evacuation guidance and information.
- Support communication between residents, barangay personnel, and emergency responders.
- Explore LoRa technology as an alternative communication method when conventional networks are unavailable.

## Key Features

### Resident Mobile Application

- User registration and login
- Emergency incident reporting
- Emergency alerts and notifications
- Evacuation guidance and information

### Barangay / Admin Dashboard

- View submitted emergency reports
- Monitor reported incidents
- Manage emergency alerts
- Access relevant emergency information

### LoRa Communication (in development)

- Long-range communication between compatible devices
- Transmission and reception of emergency messages
- Support for communication when internet or mobile networks are unavailable

## Technologies Used

- **Programming Language:** Kotlin / Java
- **Hardware:** ESP32 LoRa Development Board (in development)
- **Communication Technology:** LoRa (in development)
